# Явные движения из чата и размер Overlay

Изменение выполнено в `codex/flashmotion-living-v1`.

## Architecture Review

Character LLM выбирает смысл действия из доступных на текущий ход. Avatar Runtime
проверяет доступность для загруженной VRM и управляет позой, фазами и завершением.
Поворот использует расчёт опоры, досягаемости и углов суставов. По согласованию
для быстрого оборота разрешена опора на носок. Пятка и ориентация стопы меняются
вокруг неподвижной точки опоры. При завершении проверяются обе стопы.
Обычная жестикуляция сохраняет опору на обе стопы. Overlay получает итоговую позу
и ориентацию сцены от основного аватара. Fish и AudioPlayer сохраняют владение
синтезом и воспроизведением. Контракт Desktop с API сохранён.

## Изменения

- Семантика явного взмаха имеет приоритет над параметрами обычной речевой
  жестикуляции, если LLM прислала оба сигнала. После начала ответа Avatar запускает
  один жест и доводит его до возврата в стойку, включая случаи, когда реплика
  заканчивается раньше жеста.
- Для полного оборота планировщик сравнивает подходящие опорные точки и время
  переноса веса на геометрии загруженной VRM. Угловая скорость плавно растёт
  и снижается с коротким равномерным участком между ними. Ограничения опоры и
  суставов проверяются по фактической позе. При низкой частоте кадров движение
  проходит малыми проверяемыми интервалами. Для более медленного запроса и
  неподходящей начальной стойки доступен поворот с переступаниями.
- FlashMotion генерирует движение плеч, локтей и кистей для оборота с выбранной
  вариацией. Ретаргетинг использует их относительные вращения. Avatar Runtime
  проверяет суставы и пересечения, а ориентацию корпуса и опору вычисляет
  планировщик. Подготовленное движение локально для этого оборота и не
  продвигает таймлайн обычной жестикуляции.
- Запрос на поворот доступен из чата после проверки совместимости VRM. Виды
  Overlay оценивают положение кистей только для жестов рук. Поворот всего тела
  остаётся действием по просьбе, включая выключенный автовыбор в каталоге.
- Overlay вырос с 360 × 560 до 432 × 672 логических пикселей. Пропорции окна и
  настройки камеры сохранены. Миграция обновляет старую пару размеров по умолчанию
  и сохраняет другие пары размеров и заданный зум.

## Воспроизведение

Из корня экспериментального worktree выполнить `npm run build`. Скрипт ниже
использует отдельную копию профиля, настроенную пользовательскую VRM и реальный
Electron. В каждом прогоне сохраняются ограниченные измерения и видео Overlay в
`tmp/flashmotion/chat-*`.

```powershell
node apps/desktop/qualifications/flashmotion/live-chat.cjs --action=turn-preview
node apps/desktop/qualifications/flashmotion/live-chat.cjs --action=turn
node apps/desktop/qualifications/flashmotion/live-chat.cjs --action=wave
```

В исходной сборке LLM передала и `greeting`, и настройку обычной жестикуляции.
В Overlay воспроизвелась обычная поза без явного взмаха. Исходный поворот по
часовой стрелке в Preview занял 14 шагов. В сопоставимом прогоне планировщика на
той же VRM при стандартных параметрах он занял 27,3 с. Первый оборот на носке
занял 2,62 с в обычном чате. Вращение в середине было слишком резким по оценке
пользователя, поэтому фаза вращения стала длиннее, а пиковая угловая скорость
снижена. Размер окна в живом прогоне составил 432 × 672.

В итоговом [прогоне из обычного чата](../tmp/flashmotion/chat-1795239068110/report.json)
оборот с переносом веса и возвратом в стойку занял 3,47 с. Пиковая угловая скорость
по меткам поз в Overlay составила 247°/с. Генерированные движения плеч за фазу
вращения составили 21–27°, предплечий 8–10°. Сдвиг вычисленной точки опоры
оставался ниже порога 3 мм. Действие завершилось с углом 360° и двумя опорными
стопами. Голосовой ответ воспроизводился через Fish S2 Pro.

Во [взмахе из чата](../tmp/flashmotion/chat-1795239122701/report.json) правая
ладонь поднялась до уровня лица. Запястье сместилось вбок на 0,31 ширины корпуса
за фазу жеста. Обе стопы сохраняли опору во время жеста рукой.

В [отдельном речевом прогоне](../tmp/flashmotion/chat-1795239276778/report.json)
зафиксировано 287 кадров S2G в пределах 50 мс от фактически проигранного PCM.
Наибольшее расхождение среди этих кадров составило 44,2 мс. Наблюдались
движения губ и пальцев обеих кистей. Проверка отдельного контекстного выбора
позы и взгляда в этой реплике осталась без подтверждения.

Music-to-Dance остаётся за рамками эксперимента. Проверки опоры измеряют точность
кинематики. Пользовательская оценка естественности остаётся отдельным критерием.
