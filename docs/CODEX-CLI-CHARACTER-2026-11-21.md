# Codex CLI для Character LLM

## Architecture Review

На ветке `codex/flashmotion-living-v1` Electron Main выбирает провайдер через LlmGateway, запускает нативный Codex из глобальной npm-установки Windows, управляет отменой и дожидается завершения процесса при выходе. Character Tool Loop проверяет запросы инструментов. За внешние действия отвечают Action Runtime и Permission Guard.

## Что изменено

В настройках Character LLM появился провайдер Codex CLI с моделью `gpt-6-luna` и уровнем рассуждения `low`. Приложение использует существующий вход CLI в ChatGPT и механизм выбора прокси в Шио. В обычном профиле пользователя сохранён выбор Codex CLI.

## Root Cause

Первая реализация попала в корневое рабочее дерево с веткой `experiment/shio-autonomous-living-v1`. Рабочий клиент пользователя запускался из отдельного рабочего дерева `codex/flashmotion-living-v1`. При переносе изменения применены к существующему коду FlashMotion, а из легаси удалены только правки этого задания.

## Почему работает

Каждый вызов использует временный рабочий каталог, режим чтения и выключенные агентные инструменты. CLI получает контекст через стандартный ввод. Адаптер принимает ответ после успешного выхода процесса и события завершения хода. Права на инструменты Шио определяет существующий Runtime.

## Файлы

Адаптер находится в `apps/desktop/src/main/llm/CodexCliProvider.ts`, регистрация в `apps/desktop/src/main/llm/registry.ts`, регрессионные проверки в `apps/desktop/tests/unit/llm/codex-cli.test.ts`.

## Проверки

В собранном Electron-клиенте FlashMotion через поле ввода чата был задан вопрос о цвете спелого лимона. В чате появился ответ «Обычно спелый лимон жёлтый». Журнал зафиксировал для этого хода два завершённых вызова `gpt-6-luna` с `low`. Список резервных провайдеров был пуст. Проверка выполнялась в изолированном тестовом профиле. Отдельно проверены выбор модели в обычном профиле и запуск окна FlashMotion с этими настройками.

Настройки проверены на английском в светлой теме и на русском в тёмной. Проверены TypeScript, сборка, форматирование, импорт и 919 тестов Desktop. Biome завершился успешно с десятью предупреждениями.

## Ограничения

Проверена стандартная глобальная npm-установка Codex CLI 0.167.0 под Windows x64. Адаптер обрабатывает текст и возвращает готовую реплику целиком. Озвучка и движения аватара в проверку провайдера не входили.
