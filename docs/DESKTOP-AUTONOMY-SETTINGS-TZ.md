# ТЗ. Удаление вкладки «Автономность» из настроек Desktop

## Цель

Пользователь открывает чат или запускает трансляцию с обычными настройками профиля. Выбирать уровень самостоятельности Shio для этого не требуется. Удалить вкладку «Автономность» целиком. Состав раздела «Общие» сохранить.

## Границы изменений

- Удалить экран, пункт навигации, ссылки на него из каталога возможностей и трансляции, стили и строки обеих локалей, принадлежавшие экрану.
- Сохранить настройки существующих профилей и значения по умолчанию для новых. Открытие настроек, чата или выбора источника не должно менять профиль.
- Сохранить владельцев из §21F архитектуры. Main применяет режим самостоятельности, глобальную паузу и приватность. Явное обращение пользователя проходит через Conversation Admission. Трансляция требует выбора источника и разрешения Main.
- В старом профиле пауза, выключенные инициативы или приватность могут блокировать трансляцию. Показать действующую причину и дать пользователю возможность явно снять именно это ограничение. Объяснить последствия для всего профиля. Закрытие диалога сохраняет ограничение. При нескольких причинах запросить каждое согласие отдельно.
- Проверить путь параметра «Язык TTS» от настроек до распознавания микрофона, системного звука и синтеза. Зафиксировать, где действует автовыбор и где используется выбранный язык. Речевые настройки и протоколы в этом изменении сохраняются.

## Критерии приёмки

1. В русской и английской локалях, в светлой и тёмной темах навигация открывает пять оставшихся разделов. Каталог возможностей продолжает показывать состояние автономности.
2. Обычный профиль сразу переходит к выбору источника. Для профиля с ограничениями каждый подтверждённый шаг затрагивает только указанное поле. Захват начинается после выбора источника, ошибки и отмена не запускают его.
3. Целевые проверки интерфейса, политики инициатив, допуска сообщений, трансляции и речи проходят вместе с проверками типов, Biome и сборкой Desktop.

## Результат

Удалены экран, маршрут, ресурсы интерфейса и переход из карточки возможности. В карточке доступен текущий статус. Для старых профилей Main сверяет подтверждённую причину с действующим ограничением перед записью. Если причина изменилась, приложение получает актуальное состояние без записи. Снятие последнего ограничения открывает выбор источника. Глобальная пауза, режим самостоятельности и приватность по-прежнему действуют на весь профиль.

## Что делал «Язык TTS» до удаления настройки

| Где применяется | Наблюдаемое поведение |
|---|---|
| Непрерывный микрофон, в том числе в трансляции | Desktop при подключении передаёт выбранный `ru` или `en` в ASR. Whisper получает этот язык явно. [Подключение микрофона](../apps/desktop/src/renderer/runtime/SpeechInputRuntime.ts), [распознавание](../apps/api/app/asr/whisper.py). |
| Системный звук трансляции | Для звука ролика Desktop передаёт `auto`. При стандартной конфигурации Speech API язык определяет Whisper. [Захват системного звука](../apps/desktop/src/renderer/runtime/WatchPlaybackSpeech.ts), [обработка запроса](../apps/api/app/routes/ws.py). |
| Озвучка ответа | Перед отправкой в Fish Desktop подготавливает текст на выбранном языке. В русском режиме `TypeScript` превращается в «тайпскрипт», в английском остаётся `TypeScript`. Правила также затрагивают версии, адреса и пути. [Обработка фрагмента речи](../apps/desktop/src/main/app/SpeechApplicationService.ts), [тесты произношения](../apps/desktop/tests/unit/speech-polish.test.ts). |
| Fish S2 Pro | Язык определяет фразу прогрева. Для синтеза воркер получает подготовленный текст, теги подачи и голосовой референс. Отдельная команда выбора языка произношения в воркер не передаётся. [Прогрев](../apps/api/app/routes/tts.py), [формирование запроса к воркеру](../apps/api/app/tts/fish.py). |

По результатам этой проверки переход на автоматический выбор вынесли в отдельную задачу. Её реализация описана в [отчёте об автоматическом выборе языка речи](./DESKTOP-AUTOMATIC-SPEECH-LANGUAGE.md).

## Проверки и ограничения

Прошли 153 целевых теста Desktop и 47 тестов Speech API. Проверены типы, форматирование, порядок импортов и сборка Desktop. Biome завершился с 10 предупреждениями вне изменённых участков. Живой Electron, захват реального экрана и оценка произношения на слух в эту проверку не входили.
