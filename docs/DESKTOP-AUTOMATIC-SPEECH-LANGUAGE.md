# Автоматический выбор языка речи в Desktop

## Architecture Review

По §16 архитектуры Desktop подготавливает текст для озвучки. Speech API распознаёт звук и синтезирует речь. Для каждого ответа Desktop открывает один поток Fish. Выбор языка выполняется локально по мере поступления текста.

## Что изменено

- Из раздела «Звук» убран выбор русского или английского языка. Настройки громкости, выбора и проверки микрофона доступны в том же разделе.
- При подключении и переподключении микрофона Desktop отправляет `auto` в ASR. Микрофон чата, микрофон трансляции и системный звук используют один протокол. При стандартной конфигурации сервера Whisper определяет язык входной речи.
- Для озвучки Desktop выбирает русские или английские правила по словам самой Shio. Для смешанного текста учитываются границы предложений. Код, ссылки и технические названия сами по себе не определяют язык. Подготовка текста выполняется до отправки в Fish и не требует ещё одного запроса к модели.
- Неоднозначный фрагмент наследует язык текущего ответа. Если контекста ещё нет, используется сохранённый язык старого профиля либо текущий язык интерфейса. Этот же резервный язык определяет фразу прогрева голоса.

## Root Cause

Одно поле `ttsLanguage` управляло языком распознавания микрофона и правилами чтения текста. Например, в английском интерфейсе с русским языком озвучки Whisper получал явное указание распознавать микрофон по-русски.

## Почему фикс работает

Для ввода выбор делает распознаватель. Для вывода Desktop подготавливает очередной готовый фрагмент сразу. Например, в русском предложении `TypeScript` читается как «тайпскрипт», а в английском сохраняет английское написание. Смена языка в ответе сохраняет текущий сеанс синтеза. Схема профиля версии 10 переносит поддерживаемое старое значение во внутренний резерв. Новый профиль следует за изменениями языка интерфейса.

## Проверки

Целевые тесты охватывают язык ASR при переподключении, русские и английские предложения в одном потоке, нейтральное начало нового ответа, загрузку старых и новых профилей после перезапуска, а также раздел «Звук» в обеих локалях и темах.

Прошли 201 тест Desktop и 47 тестов Speech API. Проверки типов, форматирования и импортов, сборка Desktop и проверка речевых ресурсов прошли. Biome сообщил о 10 предупреждениях вне изменённых участков.

## Ограничения

Автовыбор правил произношения поддерживает русскую и английскую речь. В предложении с обоими языками выбор определяет преобладающее число распознанных слов, при равенстве применяется резерв. У Speech API остаётся собственная конфигурация языка ASR.

## Живая проверка 27 ноября 2026 года

На Windows запущена свежая сборка Electron из ветки `codex/desktop-companion-v1` с отдельным профилем. Работали Whisper medium на CUDA, Character через Codex CLI и Fish S2 Pro в режиме реального синтеза. Записи Windows-голосов Ирины и Зиры подавались в виртуальный микрофон. Трансляция захватывала отдельное тестовое окно через штатный выбор источника. Для проверки звука источника использовалась изолированная тестовая дорожка.

| Сценарий | Результат |
|---|---|
| Голосовой ввод в обычном чате | Приложение отправило запись в `/recognize` без указания языка. Для вопроса про небо Whisper вернул `ru` с вероятностью 0,984, для вопроса про снег — `en` с вероятностью 0,996. Смысл обоих вопросов сохранился. Обращение «Шио» распозналось как «Ш». |
| Микрофон трансляции | В одной сессии `/ws/asr` со значением `auto` распознаны русский вопрос про цвет неба и английский про цвет снега на экране. Обе реплики появились в чате, Shio ответила по содержанию. |
| Звук источника | При выключенном микрофоне отдельный поток `auto` распознал русскую и английскую записи. Счётчик пользовательских сообщений не изменился. |
| Двуязычный ответ | Проверены шесть ответов, включая ответы на голосовые запросы. Каждый прошёл одним сеансом Fish до окончания воспроизведения в AudioPlayer. Запись снималась после регулировки громкости. Фрагменты проверены повторным распознаванием по аудио, без текста-подсказки. |

В обоих режимах контрольную пару «Сегодня над рекой светит солнце. The little green boat is crossing the river.» удалось восстановить с выхода плеера слово в слово. Английская половина совпала во всех шести ответах. В развёрнутом русском описании погоды контрольный Whisper передал смысл, но изменил окончание слова «синее».

**Воспроизводимое отклонение.** В трансляции Shio дважды получила для озвучки точный текст «На экране снег белый. The snow on your screen is white.» Первый ответ последовал за голосовым вопросом, второй — за текстовой просьбой повторить фразу. В обеих записях русский фрагмент оказался неразборчивым для контрольного Whisper. Автоопределение дало английский. Принудительный русский тоже не восстановил текст. Первая дорожка в исходном PCM от Fish дала тот же результат до AudioPlayer. Для сравнения, запись тех же четырёх слов голосом Ирины распозналась точно в режиме `auto`. Эта проверка локализует расхождение до воспроизведения, но не устанавливает причину внутри модели.

В отдельной попытке с паузой перед уточнением Whisper вернул оба финальных фрагмента. Для первого проверка адресности трансляции сообщила `unavailable`, для второго — `addressed`. В чате появилось только уточнение. Это отдельное наблюдение по допуску распознанной речи.

На этой машине записи, результаты распознавания и сводка прогона сохранены в [каталоге живой проверки](../runtime-debug/shio-live-bilingual-492d5fb0/). Физический микрофон, динамики и субъективную естественность акцента эта проверка не оценивала.

## Разбор короткой русской реплики Fish

Обе исходные записи содержат точный текст на входе Fish. Дефект слышен уже в исходном PCM. На тех же записях Parakeet тоже потерял русские слова. При прямом запросе к Speech API с исходным английским образцом Makima контрольный Whisper ошибся во всех восьми повторах фразы «На экране снег белый». Английская половина и контрольная запись тех же русских слов голосом Ирины помогли исключить потерю текста при передаче и ошибку воспроизведения.

В контролируемом сравнении модель, голос, целевой текст и настройки синтеза были одинаковыми. К исходному английскому образцу добавили русскую фразу, произнесённую Fish тем же голосом. После этого Whisper дословно восстановил целевую фразу пять раз из пяти. Сам по себе тег `[speaking Russian]` с исходным образцом помог только в двух случаях из трёх. С русским контекстом в виде кодов Fish получилось девять точных результатов из десяти, с контекстом и тегом вместе — десять из десяти. Для отдельной фразы «Снег лежит на крыше» оба варианта дали десять точных результатов из десяти.

### Реализация

В рамках §16 архитектуры подготовка голоса принадлежит Speech API. Рабочий процесс Fish получает коды фиксированной русской фразы из исходного образца выбранного голоса. Он добавляет их к кодам оригинала и сопоставляет с точным текстом обеих записей. Это применяется к фрагментам с русскими буквами у голосов с английским образцом. Для русского текста без латиницы адаптер также ставит языковой тег. При выборе режима учитывается только произносимый текст, включая случаи, когда оба языка пришли в одном потоке.

Калибровка использует собственное воспроизводимое состояние генератора. Коды хранятся в памяти одного рабочего процесса, до восьми записей, с привязкой к контрольным суммам исходного звука, текста и ревизии модели. Для голоса по умолчанию подготовка входит в прогрев. Для другого английского голоса первый русский фрагмент может потребовать дополнительного прохода. Если расширенный контекст выходит за бюджет модели или калибровочная фраза оборвалась, используется исходный образец. Отмена действует и при подготовке голоса. В поток PCM попадает только текст ответа.

### Приёмка на текущей ветке

Speech API перезапущен из рабочего дерева на штатном порту `8000`. Использовались Fish S2 Pro с компиляцией на CUDA, штатный голос Makima, пересобранный Electron и Character через Codex CLI. В чате и при активной трансляции тестового окна дважды отправили одну и ту же просьбу дословно произнести «На экране снег белый. The snow on your screen is white.» Каждая попытка дала два текстовых фрагмента, одну завершённую сессию Fish и одно завершённое воспроизведение AudioPlayer.

| Запись выхода плеера | Дословно по двум предложениям |
|---|---|
| Обычный чат | 2 из 2, Whisper `auto` и Parakeet. GigaAM независимо подтвердил русский текст в обеих записях. |
| Трансляция | 2 из 2, те же три проверки. Во время ответов захватывалось тестовое окно 858 × 492. |

Границы предложений в непрерывной записи сверены с исходным PCM по нескольким участкам волны. В первой версии измерения одиночный похожий звук сдвигал границу примерно на 0,7 с в двух записях и обрезал начало английского предложения при проверке. После исправления измерения те же файлы дали полный текст. Записи плеера для этого повторно не генерировались.

Отдельная проверка распознавания файла целиком дала другой результат. Без разделения языков Parakeet ошибся во всех четырёх двуязычных записях. На контрольной записи голосов Ирины и Зиры он распознал обе фразы с исходными паузами, а после удаления тишины пропустил английскую часть. Дословность в таблице измерена для каждого предложения из реального воспроизведения. Субъективный акцент и акустика помещения остаются вне этого измерения.

В отдельном голосовом прогоне Whisper в обычном чате вернул `ru` и `en` для двух записей виртуального микрофона. В русском обращении имя «Шио» распозналось как «Ш». Микрофон трансляции в режиме `auto` передал оба вопроса в чат на исходном языке, и Shio ответила на каждый. Проверки HTTP, прогрева, раннего PCM до завершения ввода, отмены и следующего сеанса прошли. Сборка Desktop, Ruff и 81 тест Speech API прошли.
