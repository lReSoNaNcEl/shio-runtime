# План интеграции обычной SOMA

Архитектурное решение: `ARCHITECTURE.md`, «Ordinary SOMA production migration». Границы Main, Avatar Runtime, Speech API, AudioPlayer и Overlay сохраняются.

Статус: пункты 1–4 выполнены; детерминированные проверки прошли. Live-проверка новой интеграции не проводилась и остаётся отдельным этапом.

1. Согласовать pin, worker, подготовку/проверку модели, контракт каталога и Main на SOMA30, 30 FPS и 60 кадров. Ограничить историю, replanning и размер сообщения; убрать зависимость действующего кода от Core8.
2. Перенести проверенный экспериментальный ретаргетинг, корректно привязать конечности и сохранить защиту лица, кистей, стоп и единое владение позой. Не выдавать наличие фазы за подтверждение качества жестов.
3. Обновить тесты, скрипты установки и актуальные инструкции; сохранить исторические отчёты и существующие пользовательские данные. Проверить сборку, типы и целевые детерминированные проверки.
4. Отдельно устранить подтверждённые замечания по README и мёртвому API-коду без изменения используемых аудиофункций; пометить старый аудит историческим.

Согласование с архитектурой: модель меняет внутренний формат существующего адаптера, не создаёт нового Runtime и не переносит владение каналами. Историческое A/B не является свидетельством готовности для всех VRM. По правилам репозитория live-проверка текущей реализации выполняется только по отдельному явному запросу пользователя.
