# Живая трансляция Шио

## Цель и приёмка

Ветка `codex/desktop-companion-v1`. Пользователь начинает сеанс на рабочем столе, видит, какое окно транслируется, может перебить Шио голосом и остановить захват за одно действие. Эмоция и жест следуют произошедшему событию. Обычная работа за компьютером может проходить в тишине.

| Сценарий | Критерий |
|---|---|
| Старт и завершение | Видны выбор источника, состояние подключения, активный микрофон, предпросмотр, остановка и сбой. Индикация соответствует живому сеансу при переходе между вкладками. |
| Новый чат | С первого экрана доступны разговор и начало совместного просмотра. Список инструментов отражает доступные возможности. Основное действие помещается в узком окне. |
| Avatar Preview | Удобно выбрать и воспроизвести доступное движение, увидеть текущее состояние и вернуть модель в обычную позу. Проверить русскую и английскую локали, светлую и тёмную темы. |
| Реакция персонажа | Взгляд и артикуляция согласованы с вниманием и звучащей речью. У дерзкой и спокойной реплики различается подача. Главный аватар и Overlay получают одну скомпонованную позу. |
| Инициатива браузера | Пользователь может указать страницу для сверки или разрешить Шио самой подобрать статью в Википедии. По смыслу события Шио один раз за сеанс может открыть страницу в собственном Chrome. Следующий комментарий учитывает только подтверждённый результат. Остановка, смена политики или начало речи отменяют ожидающую работу. |
| Инструменты в разговоре | Во время трансляции явная просьба об операции с браузером или терминалом проходит через существующие плагины, Action Runtime, Permission Guard и проверку результата. Содержание кадра и системная речь не задают команды. |
| Задержка | Обычная голосовая просьба описать кадр получает короткий путь без повторного решения той же моделью. Сравнить число запросов и время до текста на Codex CLI, `gpt-6-luna`, effort `low`. Проверки контрактов остаются воспроизводимыми с фиксированными ответами. |

## Архитектура

Main владеет временем жизни сеанса и областью разрешённой сверки. Источник разрешения на действие — выбор пользователя или его явная реплика. Обнаружение события и выбор момента принадлежат существующему циклу наблюдения. Микрофон, очередь речи и выдача хода остаются у Speech Input и Conversation Admission. Все внешние операции выполняют действующие адаптеры. UI читает проекции этих владельцев. Для проверки используются изолированные профили и тестовые страницы.

После успеха 149/149 через 6,37 с сама связала результат с обещанием пойти спать. Повтор успешного кадра обработан за 3 мс без обращения к модели. В предыдущей серии — 8,78 с и 14,05 с соответственно. В каждой серии шесть чередующихся запусков при одинаковой расшифровке и синтетическом кадре на Codex CLI, `gpt-6-luna`, `low`, с системным прокси. |
| Браузер | Когда в проверочном окне появилось противоречие, Шио сама открыла выбранную страницу и получила подтверждённое наблюдение. В другом сеансе модель сама выбрала статью о множестве Мандельброта, а Chrome открыл точный адрес. Обе проверки прошли с одной навигацией за сеанс. Доступность статьи определяется по ответу HTTP 2xx, адресу и верификации Action Runtime. В отдельном 15-минутном сценарии управляемый Chrome выполнил 279 действий на публичных сайтах. Проверены переходы к якорям страниц с ответами 200 и 404, а также остановка трансляции во время запуска Chrome: запрос к отменённому адресу не ушёл. |

| Восстановление озвучки | На прогретом сервере первые данные PCM получены через 262 мс от запроса к Fish. При холодном восстановлении первый сокет оборвался до готовности, второй дождался загрузки. Ожидающая фраза передана один раз, получено 65 536 сэмплов в пяти чанках и подтверждено завершение. В этом прогоне ожидание первого PCM заняло 64 с. |
| Исключение Overlay | В настоящем захвате монитора под видимым Overlay прочитался зелёный пиксель тестового окна. После окончания сеанса на том же месте был виден цвет Overlay. |

После сбоя классификатора обращение можно продолжить голосом. Инструменты доступны для введённого сообщения или когда Main подтвердил точную фразу с микрофона как обращение к Шио. Решение принимает модель по словам пользователя и двум признакам недавнего разговора. Изображение и экранный текст поступают отдельно при подготовке содержательного ответа.

Финальная проверка прошла на 998 тестах Desktop и 66 тестах API. После перезапуска рабочего API проверены распознавание русского вопроса по HTTP, четыре финальные фразы через WebSocket и реальный поток Fish с ранним PCM, подтверждениями и завершением. В проверке потока на прогретом сервере первые данные пришли за 249 мс.

Для повторения проверок модели из `apps/desktop` доступны `npm run qualify:watch`, `npm run qualify:watch:autonomous` и `npm run qualify:speech-motion -- --codex-luna-low`. Квалификаторы Node используют прокси из окружения, Electron также разрешает системный прокси. Полный детерминированный набор тестов запускается из корня через `npm run desktop:test:regression` и `npm run api:test`.

Проверку трёх голосовых вопросов повторяет команда `npm run qualify:watch:voice` из `apps/desktop`. Нужны Windows, собранный клиент, запущенный API с готовым ASR и вход в Codex CLI. Windows System.Speech создаёт тестовую WAV на месте из четырёх фраз. Требуется установленный русский голос рабочего стола, например Microsoft Irina Desktop. Команда показывает только тестовое окно Spaces, подаёт запись вместо микрофона и проверяет три расшифровки, их появление в чате и три ответа по содержимому окна. На итоговой сборке получены четыре финальные расшифровки и три ответа с деталями страницы Spaces. После проверки временный профиль удаляется.
