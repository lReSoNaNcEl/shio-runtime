# Обновление каталога OpenRouter

Исправление проверено в `codex/flashmotion-living-v1`.

## Architecture Review

Каталог остаётся в Electron Main. Настройки получают список через существующий
IPC, Browser Control использует тот же клиент через LlmGateway. Настроенный
ключ передаётся только API OpenRouter. Сетевые диагностики показывают
фактический адрес запроса и скрывают заголовок авторизации.

## Причина и исправление

Клиент каталога создавал Axios без базового адреса. Относительный `/models`
завершался локальной ошибкой до обращения к OpenRouter. Настройки превращали
её в красный статус основной модели, Browser Control записывал предупреждение
при обновлении возможностей модели.

Клиент каталога теперь использует базовый адрес выбранного провайдера.
OpenRouter получает настроенный ключ для запроса списка моделей при его
наличии. Сетевая диагностика использует тот же итоговый адрес, что и Axios.

## Проверки

До исправления в одном запуске воспроизведены красный статус и предупреждение
Browser Control. После исправления запросы к `/api/v1/models` вернули HTTP 200,
каталог содержал 14 бесплатных моделей, включая Nemotron 3.5 Super VL. Основная
модель получила статус «Доступно». При запуске Browser Control предупреждение
об обновлении каталога больше не появилось.
