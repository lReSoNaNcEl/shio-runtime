# Выбор резервной модели персонажа в FlashMotion

## Architecture Review

Настройки получают каталог выбранного провайдера через существующий `window.api.llm.fetchModels`. Electron Main по-прежнему отвечает за доступ к провайдеру и учётным данным. Выбранная пара провайдера и модели сохраняется через существующую настройку `llm.roles.characterFallbacks`.

## Что изменено

В разделе «Резервная модель персонажа» у каждой позиции появился список с поиском по ID и названию модели. При открытии настроек виден сохранённый ID, даже если его больше нет в каталоге. При смене провайдера пользователь выбирает модель заново. После ошибки загрузку можно повторить.

## Root Cause (если был баг)

N/A. Запрошено улучшение настроек. Прежде ID резервной модели вводился вручную.

## Почему фикс работает

Каждая строка использует общий компонент выбора модели на React Spectrum 2, загружает собственный каталог и обновляет только выбранную резервную позицию. Ответ предыдущего провайдера или аккаунта отбрасывается. Закрытые каталоги ожидают ключ, Cloudflare также ожидает идентификатор аккаунта. Для Codex CLI используется вход в ChatGPT, а публичный каталог OpenRouter доступен до ввода ключа.

## Файлы

- `apps/desktop/src/renderer/components/settings/sections/CharacterFallbackSettings.tsx` — выбор провайдера и модели, загрузка каталога и обработка ошибок.
- `apps/desktop/tests/renderer/settings/character-fallback.test.tsx` — тесты выбора, сохранённого значения, смены провайдера и условий доступа к каталогу.

## Проверки

- 10 тестов компонента прошли, включая выбор на русском и английском языках в светлой и тёмной темах.
- Все 930 тестов Desktop прошли в полном прогоне с `--maxWorkers=2`. В первом полном прогоне два браузерных теста и один тест планирования поворота аватара завершились ошибкой.
- Сборка Desktop, проверка типов, порядок импортов и Biome для обоих затронутых файлов прошли.
- Общие `desktop:check` и `desktop:format:check` обнаружили ошибки форматирования в девяти файлах за пределами этого изменения.

## Ограничения

Живую проверку Electron для этого переноса пользователь не запрашивал. Каталоги в тестах компонента подставлены через тестовый IPC.
