# FlashMotion в обычном чате Shio

Работа выполнена в `codex/flashmotion-living-v1`. FlashMotion обслуживает
ожидание, каталожные действия и речевые жесты. Код запуска, окружение,
ассеты и SOMA-X Hand старого провайдера удалены из экспериментального
Desktop. [Техническое задание](EXPERIMENT-FLASHMOTION-LIVING-V1.md)

## Подготовка и запуск

Нужны сборка Desktop, запущенный Fish S2 Pro и настроенный в Desktop LLM для
обычного чата. Собрать ядра CUDA, проверить контрольные суммы весов и
подготовить нормализацию в `ShioFlashMotionV1` по инструкции для Windows с RTX 5090. Для
потокового русского входа команда с `--include-s2g-inputs` получает также
модель перевода Marian `opus-mt-ru-en` в `tmp/flashmotion/ru-en`.
[Окружение и подготовка моделей](FLASHMOTION-LIVING-V1-STAGE-1.md)
· [Модель перевода и лицензия](https://huggingface.co/Helsinki-NLP/opus-mt-ru-en)

Из корня ветки выполнить запуск Desktop. Во вкладке Diagnostics проверить
готовность worker и ревизию весов.

```powershell
npm run desktop:dev
```

Для повторения живой проверки использовать обычный пользовательский профиль
как источник настроек и VRM. Стенд запускает отдельный Electron с копией
профиля и отправляет сообщения через Chat. Звук выключен для окон теста.
Fish, AudioPlayer, позиция потреблённого PCM и LipSync работают штатно.

```powershell
npm run build
node apps/desktop/qualifications/flashmotion/live-chat.cjs
node apps/desktop/qualifications/flashmotion/live-chat.cjs --hands-only
node apps/desktop/qualifications/flashmotion/live-chat.cjs --interrupt
```

Стенд пишет отчёт, скриншоты и видео Overlay в `tmp/flashmotion/chat-*`.
Флаг `--idle` добавляет 120 секунд замера ожидания перед Chat.
При сравнении прогонов можно закрепить провайдера и модель переменными
`SHIO_QUALIFICATION_LLM_PROVIDER` и `SHIO_QUALIFICATION_LLM_MODEL`.
Они влияют на копию профиля стенда.

## Владельцы и синхронизация

- Electron Main запускает один процесс FlashMotion, сверяет ревизии, владеет
  очередью, сроком задачи и завершением. Worker самостоятельно закрывается по
  EOF, в том числе во время инференса. Протокол проверяет идентичность
  аватара, плана, окна и воспроизведения.
- S2G получает ограниченный фрагмент уже синтезированного PCM Fish и допущенный
  текст. CTC привязывает распознанные слова к кадрам, Marian переводит
  подтверждённые русские слова для словаря BEAT2. AudioPlayer задаёт позицию
  показа в исходных сэмплах 44,1 кГц. Когда признаки недоступны, окно
  обслуживает T2M. Обработка движения не задерживает речь.
- Avatar Runtime применяет позу, опору и пределы суставов. Нативные вращения
  S2G привязаны к нейтральной кисти VRM и проходят ограничение скорости из
  предыдущей показанной позы. T2M использует заданную геометрию кисти для
  каталожных жестов. Overlay получает итоговую позу. Мимика и LipSync
  остаются у действующих владельцев.

## Плавность

До настройки фильтра вращения пальцев на границах окон поступали в аватар
без ограничения шага. Один переход дал 51,9° на пальцевом суставе между
двумя обновлениями pose projection. После настройки максимальный
наблюдавшийся шаг составил 10,2°. Для корпуса снижены пределы скорости и
ускорения уже существующего фильтра присутствия.

| Метрика при обычном Chat | До настройки | После настройки |
| --- | ---: | ---: |
| Максимальный шаг пальцев в проекции Overlay | 51,9° | 10,2° |
| Скорость пальцев, p95 | 186,6°/с | 97,1°/с |
| Скорость рук и плеч, p95 | 86,2°/с | 68,6°/с |
| Скорость корпуса, p95 | 17,2°/с | 16,2°/с |

Оба прогона использовали пользовательскую VRM и один сценарий Chat.
Генерация живых ответов и частота обновлений различались. Исходные отчёты
сохранены в `chat-1795230631038` и `chat-1795230784277`. Числа описывают
проекцию, полученную Overlay. Художественная оценка остаётся отдельной.

После удаления старого адаптера записано 120,01 с в режиме ожидания.
В 3600 обновлениях проекции максимальный шаг корпуса составил 0,32°,
рук и плеч 0,92°. P95 скорости корпуса 3,77°/с, рук и плеч 5,04°/с.
В том же запуске средняя частота всей записи Overlay составила 55,67 FPS.
Отчёт и запись находятся в `tmp/flashmotion/chat-1795231501162`. Короткий
ответ выбранного там OpenRouter прошёл через T2M, поэтому этот запуск
подтвердил ожидание и работу Fish после удаления старого адаптера.

## Русская речь после удаления старого адаптера

В копии профиля стенда использован `ministral-14b-2512`. Обычный Chat
выдал русскую реплику, Fish воспроизвёл её с LipSync. Из 481 наблюдения
во время речи 332 содержали применённую позу S2G. Максимальная разница
между курсором AudioPlayer и применённой позой в этих наблюдениях составила
43,29 мс. Остальные 149 наблюдений пришлись на T2M, в том числе в начале
и между речевыми окнами. Проверена динамика всех 30 костей пальцев в
проекции Overlay. [Живой стенд](../apps/desktop/qualifications/flashmotion/live-chat.cjs)

Замеры всей реплики и захват Overlay находятся в
`tmp/flashmotion/chat-1795232052619`. Во второй короткой реплике S2G не
наблюдался, поэтому Stop проверялся отдельным запуском. После закрытия
Electron стенд подтвердил выход процесса FlashMotion.

В отдельном запуске `tmp/flashmotion/chat-1795232541646` команда Stop
прервала звучащую реплику на активном S2G. В 65 наблюдениях после остановки
ни одного применённого речевого кадра не осталось. Worker перезапустился,
возобновил T2M и завершился после выхода Electron. В этом же запуске
последующий Preview не показал фазу жеста. Проверка геометрии выполнена
отдельно.

## Жесты на пользовательской VRM

После чистого запуска `tmp/flashmotion/chat-1795232680127` повторили оба
жеста с seed 42. В фазе stroke правая рука показала V с углом 17,21° между
указательным и средним пальцами. У жеста открытой ладонью проекция
направления правой ладони вперёд составила 0,891 при минимуме 0,55.
Сгиб указательного и среднего пальцев составил 9,41° и 8,60° при пределе
35°. Для этих фаз сохранены скриншоты в Preview и Overlay.

```powershell
node apps/desktop/qualifications/flashmotion/live-chat.cjs --hands-only
```

## Проверки и открытые пункты

Прошли сборка, typecheck, Biome, проверка импортов, синхронизация каталога,
888 тестов Desktop, 24 теста протокола Python и пять тестов входа
FlashMotion. В повторной общей регрессии после параллельных изменений в
ветке прошёл 881 тест. Два теста Browser Control получили
`NAVIGATION_FAILED` и прошли при отдельном повторе.

Цель 60 FPS пока не подтверждена. Покрытие речи S2G остаётся прерывистым.
Для полной приёмки нужны парное сравнение с базовой веткой, квалификация
всего каталога в живом режиме на VRM0 и VRM1 и измерение p95 полного пути
подготовки речевого окна. Результаты офлайн VRM0 и VRM1 и условия лицензий
зафиксированы отдельно. [Первый этап](FLASHMOTION-LIVING-V1-STAGE-1.md)

Эксперимент использует каталог типизированных намерений. Запястья, корпус
и ноги ограничены анатомией и опорой. S2G выдаёт локальные вращения
пальцев. Танцы и Music-to-Dance вне ТЗ данной ветки.
