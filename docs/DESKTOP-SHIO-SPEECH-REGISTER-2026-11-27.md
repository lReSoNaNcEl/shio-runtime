# Речевой стиль Шио в чате и трансляции

## План

1. Уточнить разговорный стиль в каноне персонажа и при чтении экрана.
2. Отсеивать навязчивые повторы в автономных репликах по уже озвученной истории сеанса.
3. Собрать и перезапустить Desktop, проверить ответы на локальной Gemma.

## Architecture Review

Канон персонажа по-прежнему входит в запрос Character LLM через ограниченный Character Request Composer. Watch Together выбирает допустимую автономную реплику за счёт собственной короткой истории уже озвученных реплик. Дальнейший допуск реплики проходит через существующие Attention и Conversation Admission. Контракт Desktop–Speech API сохранён.

## Root Cause

Канон перечислял однотипные жаргонные слова как образцы речи. При прямом вопросе об экране промпт предлагал сперва шутить, соглашаться или возражать. Фильтр автономных реплик учитывал повторяющееся начало и отдельную матерную концовку, поэтому повтор того же словечка в середине фразы проходил.

## Что изменено

- При описании экрана Шио начинает с видимых фактов. В рабочих сценах задан спокойный разговорный язык. Сленг остаётся редкой реакцией на конкретный момент.
- «Кожаный» относится к собеседнику, «Кожаные» к людям в лёгком диалоге. Канон ограничивает их редким дружеским обращением.
- Для автоматических комментариев Watch Together проверяет повтор привычных слов и обращения. При повторе сервис берёт следующую допустимую формулировку или оставляет момент без реплики.

## Проверки

- Прошли Desktop build, TypeScript, Biome и 88 профильных тестов. Biome сообщил десять существующих предупреждений.
- На синтетическом кадре `gemma4:e4b` назвала заголовок, статус сборки и результат 18 из 18. На просьбы о дружеском обращении модель использовала обе формы. В двух коротких автоматических наблюдениях рабочей доски сервис вернул тишину.
- Запущена свежая сборка Shio с `gemma4:e4b`. Старый процесс не вышел после штатной попытки закрытия и был завершён по проверенному PID.

## Ограничения

Прогон модели охватывал синтетический кадр и несколько коротких запросов. В обычном техническом ответе E4B всё ещё привела игровое сравнение. Частота прозвищ, произнесённых без просьбы, по короткому прогону не оценивалась.
