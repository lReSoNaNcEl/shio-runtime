# Зрение и каталог моделей Codex CLI в FlashMotion

## Architecture Review

Electron Main получает модели и запускает Codex CLI через существующий адаптер. Screen Context нормализует картинку и передаёт вложение по идентификатору в пределах одного хода. Адаптер даёт CLI доступ к байтам через временный именованный канал Windows и закрывает его при завершении запроса. Снимки не записываются на диск.

## Что изменено

Настройки получают модели через `codex debug models` с текущим входом в ChatGPT и показывают записи с видимостью `list`. Поддержка изображений и доступные уровни рассуждения определяются отдельно для каждой модели. Уровень можно выбрать в настройках основной или резервной модели и в центре настройки. Выбор сохраняется для конкретной модели. Для Luna предустановлен `low`, для остальных действует уровень из каталога Codex.

## Root Cause (если был баг)

Первая версия адаптера возвращала единственную модель, при загрузке настроек принудительно подставляла Luna и принимала только текст.

## Почему фикс работает

Настройки сохраняют выбранный ID и выбранный для него уровень рассуждения. Адаптер передаёт их в `codex exec` через `--model` и `model_reasoning_effort`, а для каждого вложения передаёт отдельный `--image`. Порядок вложений соответствует ссылкам в сообщениях.

## Файлы

- `apps/desktop/src/main/llm/CodexCliProvider.ts` и `CodexImageInput.ts` — каталог, вызов модели и передача изображений.
- `apps/desktop/src/main/llm/config.ts` и `registry.ts` — сохранение выбора и возможности конкретной модели.
- `apps/desktop/tests/unit/llm/codex-cli.test.ts` — выбор модели, каталог, порядок вложений и недопустимые входные данные.
- `CodexReasoningPicker.tsx` используется в `LlmSettingsSection.tsx`, `CharacterFallbackSettings.tsx` и `SetupCenter.tsx`. Уровень проходит из конфигурации модели через существующий LLM Gateway.

## Проверки

В обычном профиле Шио Electron вернул десять моделей и подтвердил зрение Luna. В чат перетащили PNG со случайным шестизначным кодом `525755`. Имя файла и запрос не содержали ответа. В чате появился ответ `525755`. На этом ходу журнал адаптера зафиксировал `model: gpt-6-luna`, `effort: low` и `imageCount: 1`. Резервные модели в профиле отсутствовали.

В изолированном профиле выбор `gpt-6.2-sol` подтверждён реальным ответом и журналом провайдера. Для `gpt-6-sol` в светлом английском интерфейсе выбран `high`, после перезагрузки тёмный русский интерфейс восстановил этот выбор. Сборка Desktop, TypeScript, проверка импортов и форматирования прошли. Общая проверка Biome завершилась с десятью предупреждениями. Обычный клиент FlashMotion заново запущен.

В настройках основной модели для Sol выбран `low` вместо предустановленного `medium`. Шио ответила на запрос, в журнале подтверждены `gpt-6-sol` и `low`. После переключения на Luna интерфейс показал «По умолчанию (low)». Шио прочитала новый код `318794` с PNG в чате, в журнале подтверждены Luna, `low` и одно изображение.

Финальный полный прогон Desktop с одним процессом Vitest прошёл, 929 из 929 тестов. При предыдущем параллельном прогоне завершились ошибкой два теста Browser Control.

## Ограничения

Проверено на Windows с Codex CLI 0.167.0. Список зависит от текущего входа и каталога установленного Codex. Проверка зрения выполнена для Luna.
