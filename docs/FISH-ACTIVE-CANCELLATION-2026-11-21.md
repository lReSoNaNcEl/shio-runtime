# Восстановление Fish после отмены активного синтеза

## Architecture Review

Speech API владеет единственным процессом Fish. Процесс подтверждает завершение работы на GPU, затем API освобождает сессию. Формат HTTP 2.1 и `/tts/stream` v2 сохранён. AudioPlayer владеет локальным воспроизведением и позицией PCM.

## Что изменено

Для запроса на синтез API выставляет межпроцессный сигнал отмены. Обёртка над закреплённым декодером проверяет его между шагами генерации и на границе вывода PCM. Процесс синхронизирует CUDA и отвечает завершением запроса. API отбрасывает оставшийся PCM до подтверждения, удерживая блокировку синтеза. Если подтверждение не приходит за секунду, API останавливает процесс и начинает аварийное восстановление.

## Root Cause

До исправления Stop во время синтеза всегда завершал процесс Fish. Повторная загрузка и прогрев занимали 102,89–108,53 с на измеренной конфигурации. В предыдущей правке прогретый процесс сохранялся только при отмене между запросами.

## Почему фикс работает

Обычная отмена выходит из цикла декодирования и ждёт завершения уже поставленной работы CUDA. Загрузка модели, состояние компиляции и прогретый референс остаются в процессе. Перед следующим запросом API сбрасывает сигнал отмены после обработки терминального сообщения предыдущего запроса.

## Файлы

- `fish.py` владеет сигналом отмены, очередью и аварийным восстановлением.
- `fish_streaming.py` и `fish_worker.py` прерывают генерацию внутри процесса.
- `tts_stream.py` закрывает генератор при отмене, чтобы дождаться его очистки перед освобождением сессии.

## Проверки

Прошли 67 тестов API, Ruff и проверка форматирования. Регрессии покрывают остановку декодирования до терминального результата, отбрасывание оставшегося PCM, повторный запрос и аварийный путь при отсутствии подтверждения.

На реальном Fish S2 Pro с CUDA и компиляцией `/tts/stream` выдал PCM до `finish-input`. Отмена после первого PCM получила подтверждение за 68 мс. Следующая сессия получила первый PCM за 243 мс от открытия. PID процесса сохранился в проверке протокола и в Electron.

В паре сопоставимых прогонов Electron с Codex CLI `gpt-6-luna` время от Stop до первого сигнала следующей реплики сократилось с 103,43 до 9,58 с. В новом прогоне Fish остался готов, от запроса на озвучку до первого звука прошло 258 мс.

## Ограничения

Замер Electron выполнен в изолированном FlashMotion-профиле без OBS. Для аварийного пути использован детерминированный тест без искусственного зависания реальной CUDA.
