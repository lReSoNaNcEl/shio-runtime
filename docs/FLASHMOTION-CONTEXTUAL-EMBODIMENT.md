# Контекстные движения Shio

Эксперимент `codex/flashmotion-living-v1` использует решение Character LLM
для взгляда, позы и жестикуляции в текущей реплике. Предложение содержит
цель взгляда, взгляд на паузе, наклон вперёд и в сторону, размах жестов и
предпочтение ведущей руки. Эти параметры выбираются из смысла разговора
в существующем этапе типизированного планирования ответа.

## Причина изменения

Обычная речь могла повторно запустить каталожный жест из планировщика
Avatar. Окна FlashMotion уже зависели от речи, но выбор позы между окнами
во многом определялся очередью профилей.

## Реализация и границы

- При доступном FlashMotion обычная реплика использует речевой поток
  движения. S2G строит новые окна по Fish. T2M подхватывает участки, где
  признаки S2G ещё недоступны. Начальное состояние S2G привязано к
  воспроизведению реплики, а не ко всей сессии аватара.
- Avatar Runtime плавно меняет наклон и амплитуду рук на текущей позе.
  Во время слышимой паузы амплитуда снижается, а арбитр взгляда может
  принять выбранную Shio цель на паузе. Нормализация запястий, пределы
  суставов, коллизии и опора стоп применяются тем же владельцем.
- Выбор действует в пределах реплики и уступает режиму слушания.
  Overlay получает итоговый режим взгляда вместе с позой.
  Каталог используется для явно запрошенных жестов и Debug Preview.

## Architecture Review

Character LLM предлагает ограниченные данные для показа. Текущее
допущенное состояние разговора определяет их срок действия. Avatar Runtime
владеет арбитражем взгляда, применением позы, анатомическими ограничениями
и опорой. Electron Main владеет FlashMotion worker, AudioPlayer владеет
таймингом по потреблённым сэмплам, а Overlay потребляет проекцию.
Сервис Fish продолжает отдавать PCM по HTTP 2.1 и `/tts/stream` v2.

## Повторение проверки

```powershell
npm run build
$env:SHIO_QUALIFICATION_LLM_PROVIDER = 'mistral'
$env:SHIO_QUALIFICATION_LLM_MODEL = 'ministral-14b-2512'
node apps/desktop/qualifications/flashmotion/live-chat.cjs --context=reflection
node apps/desktop/qualifications/flashmotion/live-chat.cjs --context=celebration
```

Стенд использует настроенную VRM и изолированную копию профиля. Он
сохраняет измерения, подтверждённые значения параметров и видео Overlay
в `tmp/flashmotion/chat-*`.

## Результаты

На одной пользовательской VRM прошли два живых разговора с Fish и Mistral
`ministral-14b-2512`. Модель получила обычные русские реплики без указания
взгляда, наклона или ведущей руки.

| Контекст | Наклон вперёд | Размах жестов | Предпочтение руки | S2G во время речи | Максимальное расхождение с Fish |
| --- | ---: | ---: | --- | ---: | ---: |
| Усталость и сомнение | 0 | 0,50 | Обе стороны | 524 из 576 наблюдений | 42,77 мс |
| Успех проекта | +0,50 | 0,80 | Правая, +0,50 | 544 из 582 наблюдений | 42,24 мс |

В обеих репликах Shio выбрала взгляд на собеседника. Во время речи
использовались профили присутствия, а пальцы двигались вместе с речевой
жестикуляцией. Отчёты и видео находятся в `tmp/flashmotion/chat-1795234033200`
и `tmp/flashmotion/chat-1795234225823`. После выхода в обоих прогонах worker
завершился.

Интеграционные тесты проверили смену взгляда в паузе, выход из контекста
при смене реплики, отсутствие автоматического каталожного жеста во время
речи и смещение обеих стоп менее 1 см при смене позы в тестовой модели.
Обычная регрессия Desktop прошла все 886 тестов. Также прошли typecheck,
сборка, Biome, импорт, синхронизация каталога и 24 теста протокола Python.

Живых сценариев было два. Они проверяют вариативность движений, а смена
взгляда в паузе подтверждена тестом по потреблённому PCM. На части речевых
окон видна анимация T2M.
