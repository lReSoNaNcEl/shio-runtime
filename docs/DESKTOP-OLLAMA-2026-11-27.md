# Локальный провайдер Ollama в Shio Desktop

## План

1. Установить официальный Windows CLI Ollama и загрузить `gemma4:e4b`.
2. Зарегистрировать Ollama в существующем каталоге провайдеров Character LLM.
3. Проверить локальный ответ в Electron, расход видеопамяти и сохранение выбора в профиле.

## Architecture Review

Electron Main владеет обращениями к Ollama и использует существующий адаптер Chat Completions. Проверка IPC, планирование Character, выполнение инструментов, отмена и обработка потока остаются в существующих компонентах. Shio обращается к запущенному пользователем локальному серверу без API-ключа, прокси и HTTP-перенаправлений. Контракт Desktop и Speech API не менялся.

## Реализация

- Ollama CLI 0.40.18 установлен из официального Windows-архива после сверки SHA-256. Сервер слушает `127.0.0.1:11434` с `OLLAMA_NO_CLOUD=1`. После перезагрузки его можно запустить командой `ollama serve`.
- Настройки Character показывают установленные модели из `/api/tags` и отбрасывают записи с удалённым хостом. `gemma4:e4b` предлагается по умолчанию при выборе Ollama. В действующем профиле активирована эта модель без запасного провайдера.
- Для основных тегов Gemma 4 заявлены изображения и нативные вызовы инструментов. Расширенный режим рассуждения выключен для сокращения задержки. Структурированное планирование по JSON Schema выполняет та же модель.

## Проверки

- Прошли `desktop:check`, `desktop:format:check`, `desktop:imports:check`, `typecheck`, `build` и 66 целевых тестов. Biome сообщил десять предупреждений вне изменений Ollama.
- Первый запуск на этой машине превысил исходный лимит провайдера в 60 секунд из-за инициализации CUDA-раннера. Для Ollama задан лимит 90 секунд на запрос и начальные стадии потока. Таймаут между фрагментами и общий лимит Character Tool Loop сохранены.
- После выгрузки модели повторный запуск прошёл путь от JSON Schema до финального потокового ответа на русском в Electron за 6 секунд. Проверены каталог и настройки в обеих темах. Локальный Chat Completions вернул нативный вызов тестовой функции с ожидаемым аргументом.
- Модель занимает 6,6 ГБ на диске. С контекстом 32 768 токенов Windows показала 5 728 МиБ выделенной видеопамяти процесса Ollama на RTX 5090.

## Ограничения

Полный регрессионный набор, синтез речи и обработка изображений в живом Electron не проверялись. Для сравнения качества и задержки следующая модель по размеру — `gemma4:12b`, около 8 ГБ на диске. Её скорость и VRAM на этой машине ещё не измерены.
