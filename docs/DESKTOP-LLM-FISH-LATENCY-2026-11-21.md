# Задержка ответа LLM и повторный запуск Fish

## Architecture Review

Character Tool Loop ждёт типизированное решение того же Character LLM перед выдачей текста. Для предварительной генерации нужен прямой ответ с пустым планом инструментов, без отдельного визуального действия и с совпадающим путём запроса. Публикация проходит через существующий безопасный фильтр.

Speech API владеет одним процессом Fish и удерживает блокировку до завершения либо остановки активного синтеза. Desktop и API используют HTTP 2.1 и `/tts/stream` v2. AudioPlayer владеет воспроизведением и позицией PCM.

## Что изменено

- Существующий эксперимент «Ускоренный ответ» запускает генерацию параллельно с планированием и на пути структурированных инструментов. При несовпадении плана черновик отменяется. Отмена хода прерывает запрос к провайдеру и после начала выдачи текста.
- Fish сохраняет прогретый процесс при отмене до отправки запроса на синтез или после подтверждения завершения. При отмене отправленного запроса с неподтверждённым завершением API останавливает процесс и запускает его восстановление.

## Root Cause

При наличии доступных инструментов оптимизация LLM выбирала только нативный путь. На структурированном пути даже прямой ответ ждал завершения планирования. После начала выдачи текста прежний обработчик отмены вызывал сброс, который действовал только на удерживаемый черновик. Fish при отмене завершал процесс по состоянию WebSocket-сессии, включая время ожидания очередного текста.

## Почему фикс работает

Для прямого плана структурированный путь использует те же сообщения и параметры, что и последовательный запрос, и выдаёт результаты после проверки плана. Общий сигнал запроса включает отмену хода и сброс черновика. Fish отслеживает состояние отправленного запроса по подтверждению `done`, которое приходит от процесса после завершения синтеза всех аудиоданных этого запроса.

## Файлы

- `CharacterToolLoop.ts` и `CharacterSpeculativeReply.ts` управляют порядком запросов и отменой.
- `fish.py` отслеживает завершение работы процесса Fish.
- `character-speculative-reply.test.ts` и `test_voice_conditioning.py` проверяют параллельный старт, соответствие запросов, смену плана, отмену и повторное использование прогретого процесса.

## Проверки

До исправления воспроизведены последовательный старт на структурированном пути, потеря сигнала отмены после выпуска черновика и остановка простаивающего процесса Fish. После исправления прошли 68 целевых тестов Desktop и 65 тестов API, `typecheck`, сборка Desktop, Biome, Ruff и проверки форматирования и импортов. Biome показал 10 предупреждений вне изменённых файлов.

## Ограничения

Ускоренный режим включается через существующую экспериментальную настройку. При несовпадении плана провайдер может успеть потратить токены на отброшенную генерацию. Живой прогон Electron с провайдером и Fish не запрашивался. Для оценки эффекта нужны сравнение времени до первого слышимого слова при включённом и выключенном эксперименте и отдельный замер следующей реплики после отмены.
