        Как задавать подачу речи
        

          
Как передать эмоцию на этой странице

          
Выберите Emotion / reference, а в «Текст» введите реплику. Можно начать реплику с одного тега в квадратных скобках, используя ID из списка Emotion: страница уберёт этот начальный тег и выберет соответствующую эмоцию перед отправкой.

          
[happy] Привет! Я так рада тебя видеть.
[sad] Мне жаль, что так вышло.
[whisper] Тише… это наш маленький секрет.

          
Пробуйте каждую строку отдельно. После тега обязательно добавьте непустую реплику. В списке находятся ID эмоций Shio, а не все теги, которые понимает Fish.


          
Произвольная инструкция в поле «Подача»

          
Для произвольной инструкции Fish введите её описание в поле «Подача» без квадратных скобок: до 120 символов, без угловых скобок и управляющих символов. В «Текст» оставьте слова реплики. Сервер сам добавит скобки и объединит инструкцию с Emotion, темпом, энергией и громкостью.

Начните с обычного темпа, энергии и громкости. Выбирайте совместимые инструкции и добавляйте детали постепенно. При смене примера очищайте поле «Подача». Выраженность эффекта зависит от голоса и генерации; тег не гарантирует точный тайминг.


          
Нативный синтаксис тегов Fish Audio S2 Pro

          
Сама модель принимает инструкции на естественном языке в [квадратных скобках] непосредственно перед нужными словами, в том числе посреди предложения. Инструкции можно писать по-английски или на языке реплики. У S2 Pro нет закрытого списка тегов; круглые скобки из S1 не являются нативным форматом S2.

          

            
Что задаёт тегПримеры для самой модели Fish

            
              
Эмоция[excited] [angry] [sad] [surprised]

              
Подача и реакции[whisper] [laughing] [sigh]

              
Пауза и ударение[pause] [emphasis]

            
          

          
Пример для прямого входа модели: вторая инструкция стоит в месте смены подачи.

          
[excited] Мы нашли ответ! [whisper] Но пока сохраним это в секрете.

          
Несколько тегов и повторения внутри реплики

          
На один участок текста можно накладывать несколько совместимых тегов одновременно: поставьте их подряд перед нужными словами. Например, сочетайте эмоцию с манерой речи или голосовой реакцией. Инструкции дополняют друг друга — выбирать только один тег на всю реплику не требуется.

          
[sad][whisper] Я всё ещё скучаю по тебе.

          
Теги можно ставить в начале предложения, между словами и между предложениями — в любом месте, где нужна смена подачи. Можно вводить новые теги и повторять предыдущие N раз в пределах длины входного текста. Повторный тег позволяет снова вернуться к нужной манере речи позже в реплике; каждую инструкцию ставьте перед словами, к которым она относится.

          
Я хотела сказать [whisper] спасибо… [excited][laughing] Мы справились! [whisper] Но пока это секрет.

          
S2 Pro интерпретирует смысл инструкций на естественном языке с учётом контекста, включая свободные описания и их сочетания. Поэтому модель гибко управляет подачей разных частей реплики. Используйте понятные, совместимые инструкции: больше тегов не гарантирует более сильный эффект или точное исполнение. На этой странице для первого примера можно выбрать Emotion = sad и «Подача» = whisper — сервер сформирует оба тега.

          
Особенность текущего локального API: произвольные теги внутри поля «Текст» не передаются как инструкции модели — их квадратные скобки заменяются круглыми. Страница распознаёт только один начальный тег из списка Emotion. Для свободных тегов используйте поле «Подача», как показано выше; пример прямого входа модели не предназначен для вставки целиком в «Текст».


          
Смена эмоции между фрагментами

          
    
            
  1. Включите продолжение ввода, задайте первый фрагмент и его Emotion / «Подачу», затем нажмите «Синтезировать поток».
    2. 
            
  2. Для следующего фрагмента измените Emotion / «Подачу», замените текст и нажмите «Отправить фрагмент». Например: happy для радостной новости, затем whisper для секрета.
    3. 
            
  3. После последнего фрагмента нажмите «Завершить ввод». Новая подача применяется к следующим фрагментам; уже воспроизводимый звук не меняется.
    4. 
          

          
Официальные источники: S2 Pro — Fine-Grained Inline Control, Fish Audio — S2 Inline Tags.

          
Голос выбирается через voice_manifest.json. Исходные reference.wav и reference.txt остаются неизменными, а подготовленные для модели данные хранятся отдельно в производном кэше.
