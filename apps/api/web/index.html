Как задавать эмоции в тексте

LLM может начать ответ с одного ведущего тега: [happy], [sigh], [gasp], [angry]. Backend вырезает тег из озвучки и нормализует emotion через emotion_manifest.json.

[happy] Привет! Я рада тебя видеть.

F5 не имеет sampling-пресетов эмоций. Голос выбирается через voice_manifest.json, а reference-аудио хранится в voices/<dataset>/<voice>/reference.wav вместе с reference.txt.

Какие параметры на F5-TTS влияют
ПараметрF5-TTSRuntime contract
voiceIdВыбирает logical voice из voice_manifest.json; remote sync может установить ассеты в voices/<dataset>/<voice>.Не влияет напрямую.
emotion / тегНормализуется через Emotion Registry; speech получает только speech.style.Avatar mappings остаются на стороне Shio Runtime.
languageПодсказывает языковую обработку. Для русского может использоваться RUAccent, если установлен.Не влияет напрямую.
speedНативный параметр скорости генерации F5.Меняет длительность речи и темп lipsync.
pitchПост-обработка WAV после генерации.Не влияет напрямую.
F5_NFE_STEPНастройка сервера в .env: число diffusion/inference steps. Больше обычно медленнее и потенциально чище.Не влияет напрямую.
F5_CFG_STRENGTHНастройка сервера в .env: насколько строго F5 держится reference/condition.Не влияет напрямую.
