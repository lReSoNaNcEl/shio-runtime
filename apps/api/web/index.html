Как задавать подачу речи

Выбранные emotion, темп, энергия и громкость передаются как единый delivery intent. Сам текст отправляется в поток без служебных тегов и начинает проигрываться по мере поступления PCM-аудио.

Привет! Я рада тебя видеть.

Голос выбирается через voice_manifest.json. Исходные reference.wav и reference.txt остаются неизменными, а подготовленные для модели данные хранятся отдельно в производном кэше.

Параметры Fish Audio S2 Pro Streaming
ПараметрFish Audio S2 ProRuntime contract
voiceIdВыбирает logical voice и соответствующий reference из voice_manifest.json.Один голос фиксируется на всю streaming-сессию.
